Strategie für lesbare Schrift auf Android:
1. Viewport korrekt: width=device-width, initial-scale=1 — CSS px ≠ physische px.
2. clamp() überall: font-size: clamp(1rem, 4vw, 1.2rem) — skaliert mit Viewport.
3. Basis-rem erhöhen: Auf schmalen Screens (<400px) root → 17-18px.
4. Touch-Targets: Alle Buttons/Inputs min. 48px Höhe (Material Design Guideline).
5. DPR berücksichtigen: Bei DPR=3 sind 12px-CSS-Text nur 4px physisch → winzig!
6. Kein zoom-blocking: user-scalable=no entfernen für Accessibility.
